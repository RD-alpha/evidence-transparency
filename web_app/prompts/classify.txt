WHAT A THEME IS
A theme is one line of the argument that the document makes, broad enough to hold several related points. It is not a topic label for a single detail. Group sentences by the part of the argument they play, not by shared words: sentences about different details of the same question belong together. The number of themes is not fixed. Let the document decide, but expect a handful for most extracts and fewer for short ones. If you have many themes of only a few sentences each, you have almost certainly split one line of argument into its parts, so merge them.

Sentences can appear in more than one theme. Where a sentence doesn't fit any main theme, put it in a final theme named "Other".

NAMING THEMES
Name each theme after a general area of policy, not after a named scheme, programme, group or detail. A good theme name could head a section of the document. If a name only fits a handful of sentences, it is too narrow: use the broader area it belongs to instead.
